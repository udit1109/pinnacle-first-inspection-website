# Pinnacle First Inspection Website

Static multi-page company website for Pinnacle First Inspection, using the existing industrial blue, charcoal, and amber theme.

## Pages

- `index.html` redirects visitors to the homepage.
- `pinnacle-first-inspection.html` — Home
- `about-us.html` — About Us
- `accreditations.html` — Accreditations
- `services.html` — Services
- `projects.html` — Projects and coverage
- `career.html` — Career
- `contact-us.html` — Contact Us

Shared assets: `site.css`, `site.js`, and `image.png` (logo).

## Local preview

Open `index.html` in a browser. The contact and career forms prepare email drafts using the visitor's default mail app; they do not send or store submissions on a server.

## GitHub Pages

For client preview, publish this repository with GitHub Pages using the `main` branch and `/ (root)` as the build source. The root URL will redirect to `pinnacle-first-inspection.html`.

## Publishing note

Only upload the website files listed above and the ISO certificate PDF if it is approved for public distribution. Do not upload the supplied Word documents, especially the organization chart or other working/source documents.
